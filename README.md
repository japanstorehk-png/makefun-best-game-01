Emberwatch is an original offline lighthouse game: swing the beam with the mouse or keyboard to guide drifting ships past the rocks and into the harbour, and keep the light through eight nights.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. There is no build step and the game needs no network.
